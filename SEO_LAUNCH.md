# Search launch checklist

The site is prepared for the GitHub Pages address `https://stupegent.github.io/BensounaAchour/` and repository `Stupegent/BensounaAchour`. The workflow publishes the static site files when changes are pushed to `main` or `master`.

After the repository is created and the first deployment succeeds:

1. Verify `https://stupegent.github.io/` in Google Search Console.
2. Submit `https://stupegent.github.io/BensounaAchour/sitemap.xml` and inspect the page URL.
3. Check that the page and PDF links are reachable and that the host does not add a `noindex` directive.

Google decides when and whether a page is indexed or shown for a search. A sitemap helps Google discover URLs, but it does not guarantee indexing or ranking.
